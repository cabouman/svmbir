# sv-mbirct

The supervoxel MBIR C code that svmbir compiles and wraps.

This is a copy of https://github.com/HPImaging/sv-mbirct at commit
1f26759e6afb4113f31303468a7ec517936328ec (branch master, December 2022),
written by High Performance Imaging, LLC and distributed under the
BSD 3-Clause License in LICENSE.  It was a git submodule of svmbir until
September 2026 and is now maintained here.  `src/Makefile` builds the
stand-alone `mbir_ct` program into `bin/` for the command-line interface.
